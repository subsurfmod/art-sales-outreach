# Art Seller Assistant & Outreach Engine (Rust Edition)

A complete, museum-grade operating system for selling **physical artwork** — powered by a single native Rust CLI (`art-outreach`), orchestrating all relevant 3D/2D/video/publishing skills installed on this machine, and built around **anti-slop differentiation** so every artist gets unique websites, portfolios, social videos, and outreach campaigns instead of generic AI fodder.

> **NON-NEGOTIABLE AUTHENTICITY PROTOCOL (ZERO AI ART / ZERO AI ARTIST)**
> NEVER generate AI images or AI video frames of the artwork or the artist (no `image-generator`, Midjourney, DALL-E, Flux, Stable Diffusion, HeyGen avatars, or Unsplash/Pexels stock art). Every artwork photo, macro detail, studio clip, and artist portrait MUST be an authentic file supplied by the artist, registered with `art-outreach assets register`, and verified with `art-outreach assets audit` before shipping. See [superpowers_workflow_and_authenticity.md](./references/superpowers_workflow_and_authenticity.md).

cargo build --release --manifest-path /home/slave/.agents/skills/art-sales-outreach/Cargo.toml

Recommended workspace layout (`./art-outreach-workspace/`):
```text
art-outreach-workspace/
├── artist_profile.json     # From templates/artist_profile.example.json

└── batches/                # Human-readable outreach draft review sheets
```

## Phase 0: Superpowers Kickoff & Real-Asset Lock (Always Run First)

Follow the **`obra/superpowers`** discipline — **never jump straight into generic code or blasts**:

1. **Collect Real Artist Inputs**: Medium, style/mood, physical dimensions, price tier, target cities, real portfolio/CV facts, and path to the artist's **real** photographs/scans/studio clips.
2. **Register & Screen Real Assets**:
   ```bash
   art-outreach assets register --dir art-outreach-workspace/real_assets
   ```
   *(Automatically computes SHA-256 checksums and rejects any file with AI-generator EXIF/PNG/C2PA/filename markers.)*
3. **Generate a Bespoke 4-Pillar Master Blueprint** (tailored to this specific artist — never generic fodder):
   ```bash
   art-outreach studio blueprint \
     --medium "textured oil on linen" --mood "warm minimalist" \
     --price-tier "mid-career" --city "Austin"
   ```
   Or inspect all 18 distinct variations across Website/Portfolio, 3D/2D Social Video, and Outreach:
   ```bash
   art-outreach studio variations --pillar all
   ```
4. **Present 2–3 curated variation options** to the artist with trade-offs and get confirmation before building.

## Pillar 1: Anti-Slop Artist Website & Popular-Artist Portfolio

Synthesizes **Anthropic's `frontend-design` / `prompting_for_frontend_aesthetics`**, **ASCII wireframe-first constraints**, and **contemporary artist portfolio benchmarks** (Online Viewing Rooms, Catalogue Raisonné, Academic CV, Collector Inquiry Drawer).

1. **Lock ASCII Wireframe & Anti-Slop Design DNA Before Coding**:
   Read [anti_slop_websites_and_wireframes.md](./references/anti_slop_websites_and_wireframes.md) and [popular_artist_portfolios.md](./references/popular_artist_portfolios.md), then generate the wireframe:
   ```bash
   art-outreach studio wireframe white-cube-monograph
   # Other distinct variations:
   # catalogue-raisonne | editorial-brutalist | atmospheric-salon | tactile-studio-notebook | kinetic-exhibition
   ```
2. **Build the Site Using Only Registered Real Assets**:
   - Ban Inter/Roboto/Arial defaults, purple gradients, generic SaaS cards, and "Add to Cart" buttons on unique fine-art originals.
   - Include a dedicated **Private Viewing Room (`/viewing-room/...`)** with 60"-hang View-on-Wall scale reference and contextual **"Inquire About *[Title]*"** drawer — this URL becomes the high-converting destination for email outreach & social ads!
3. **Mandatory Authenticity Audit Gate**:
   ```bash
   art-outreach assets audit --target art-outreach-workspace/website
   ```
   Must return `"passed": true` with `0` violations before delivery.

## Pillar 2: Social Media Advertising — 3D & 2D Artwork Videos

Orchestrates the **real 3D, 2D, motion, and publishing skills installed on this computer** — using **exclusively verified real artist scans/photos/clips** (NEVER AI-generated artwork or AI artist avatars!). Read [installed_skills_orchestration.md](./references/installed_skills_orchestration.md) before starting a video.

Choose distinct non-repetitive formats per campaign (`art-outreach studio variations --pillar video`):
- **3D Blender Gallery & Scale Reels** (`blender-3d-raking-light`, `blender-3d-architectural-scale`): Activate `/home/slave/.agents/skills/blender-film/SKILL.md` (and RTX 3050 EEVEE Raytracing via `run_blender_rtx3050.sh`). Map the artist's unaltered real scan onto a real-proportion 3D stretched linen canvas/frame inside a plaster gallery or architectural room; animate raking sunlight and shallow-DOF handheld camera motion.
- **2D Kinetic Exhibition & Launch Films** (`onetake-kinetic-exhibition`, `motionmaxxing-collector-film`): Activate `onetake` or `motionmaxxing` + `motion-doctrine` + `hyperframes` (strictly disabling any AI image-generation step!) for museum-grade single-take reveals from macro brushwork to full framed piece.
- **Narrated Studio Story Shorts & Splits** (`remotion-collector-story`, `macro-split-process`): Activate `remotion-best-practices` / `remotion-captions` / `ffmpeg` / `pixel2motion` (animate only the artist's real handwritten signature) for 9:16 Reels, TikToks, and YouTube Shorts.
- **Audit & Publish**:
  1. Run `art-outreach assets audit --target art-outreach-workspace/videos/<project>`.
  2. Inspect rendered frames via `read_file` to verify truthful artwork colors & proportions.
  3. Publish vertical Shorts directly with `/home/slave/Projects/video-skills/.agents/skills/youtube-shorts-uploader/SKILL.md`.

## Pillar 3: High-Reach Connector Lead Discovery & Multi-Inbox Rust Outreach

Targets **High-Multiplier Connectors** (Interior Designers, Art Consultants, Hospitality Buyers, Luxury Stagers, Galleries, Architects, Concept Stores, Press) with 6 distinct non-fodder outreach angles (`art-outreach studio variations --pillar outreach`).

1. **Initialize CRM & Discover Leads (Multi-Source, CAPTCHA-Free)**:
   ```bash
   art-outreach crm init
   # A. Targeted Google Boolean queries (run via Antigravity's built-in `search_web` tool or Search APIs)
   art-outreach discover generate-queries \
     --cities "Austin,Denver,Nashville" \
     --verticals "interior_designer,art_consultant,stager,hospitality,gallery" \
     --style "warm modern" --medium "oil painting" \
     --output art-outreach-workspace/queries.json
   art-outreach crm import-urls --file art-outreach-workspace/urls.txt --category interior_designer --location "Austin"

   # B. Free local business discovery via OpenStreetMap Overpass
   art-outreach discover osm-local --city "Austin, Texas" --limit 150

   # C. Public directory extraction (respects robots.txt)
   art-outreach discover crawl-directory --url "https://example-guild.org/members" --category interior_designer
   ```
2. **Async Website Enrichment + Live MX Verification & 0–100 Scoring**:
   ```bash
   art-outreach enrich --limit 100 --concurrency 12 --max-subpages 4
   art-outreach verify --profile art-outreach-workspace/artist_profile.json
   art-outreach crm list --mx-valid --min-score 65 --limit 30
   ```
3. **Sender Deliverability Pre-Flight (SPF / DKIM / DMARC / MX)**:
   ```bash
   art-outreach deliverability hello@yourartstudio.com
   ```
4. **Draft Multi-Touch Outreach + Human Review Gate**:
   ```bash
   art-outreach outreach generate-drafts \
     --profile art-outreach-workspace/artist_profile.json \
     --campaign "q1-connectors" --step 1 --min-score 65 --limit 25 \
     --review-out art-outreach-workspace/batches/review-touch1.md
   ```
   Show the user `review-touch1.md` + sample drafts before sending.
5. **Dispatch Safely & Run Reply/Follow-Up Loop**:
   ```bash
   # Option A: Upload directly to Gmail/Outlook Drafts folder via pure-Rust TLS IMAP
   art-outreach outreach upload-imap-drafts --senders art-outreach-workspace/senders.json --campaign "q1-connectors"

   # Option B: Multi-inbox rotated SMTP or Resend/Brevo API (always --dry-run first!)
   art-outreach outreach send --senders art-outreach-workspace/senders.json --campaign "q1-connectors" --dry-run
   art-outreach outreach send --senders art-outreach-workspace/senders.json --campaign "q1-connectors"

   # Sync replies, bounces & opt-outs BEFORE drafting Touch 2/3 follow-ups
   art-outreach outreach check-replies --senders art-outreach-workspace/senders.json --days 14
   art-outreach crm next-followups
   ```
